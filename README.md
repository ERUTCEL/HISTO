# 역사자료 연구실

조선시대 사료를 여러 공식 데이터베이스에서 한 번에 찾아 모으고, 앱 안에서 읽고 분류·분석하는 Windows 프로그램입니다.
인물·사건·제도 이름을 넣으면 관련 기록을 모아 관련성 순으로 보여주고, 연구자의 판단을 학습해 점점 더 맞는 자료를 앞으로 올려 줍니다.

![통합 검색 화면](docs/screenshots/after-search.png)

## 내려받기와 실행

1. [release/histo-v3.1.zip](release/histo-v3.1.zip)을 내려받습니다(파일 화면 오른쪽 위 ↓ 버튼).
2. 압축을 풀고 `HistoryDesk-v3.1.exe`를 원하는 폴더(예: 바탕화면의 새 폴더)에 둡니다.
3. 더블클릭해 실행합니다. 처음에 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다.

- Windows 10/11 64비트. Python 등 다른 설치는 필요 없습니다.
- 검색에는 인터넷이 필요하고, 저장된 자료를 읽고 분석하는 것은 인터넷 없이 됩니다.
- 모은 자료는 exe 옆 `수집결과` 폴더에 저장됩니다. 새 버전으로 바꿀 때 exe만 바꾸고 이 폴더는 그대로 두세요.

## 주요 기능

| 기능 | 하는 일 |
|---|---|
| **통합 검색** | 한 번 검색으로 7개 사료 데이터베이스의 결과를 모읍니다 |
| **자료원 연결** | 검색할 사이트를 고르고, 자동 수집이 안 되는 사이트는 공식 검색 화면을 바로 엽니다 |
| **문헌 결과 보기** | 모은 문헌을 앱 안에서 읽고, 점수·자료원·관점·연대로 거릅니다 |
| **관련/무관 판정 학습** | 연구자가 표시한 판정을 학습해 관련 문헌을 위로 올립니다 |
| **유사도 검색 · 비슷한 문헌** | 고유명사·원문 구절로 찾거나, 지금 보는 문헌과 비슷한 문헌을 찾습니다 |
| **어휘 관계** | 어떤 낱말과 쓰임이 비슷한 말, 자주 함께 나온 말을 시대별로 봅니다 |
| **문맥 용례** | 한 낱말이 나온 자리들을 쓰임새별로 묶어 보여줍니다 |
| **주제 · 자료 유형 자동 분류** | 적은 수의 주석으로 전체 문헌을 정치사·사회사·제도사, 상소·전교 등으로 분류합니다 |
| **여러 작업 동시 학습** | 주제·자료 유형·직접 만든 과제(예: 정치적 입장)를 함께 학습하고 따로 학습한 경우와 비교합니다 |
| **시대·출처 적응** | 다른 시대나 자료집에 분류 모델을 쓸 때 성능이 떨어지는지 재고, 보정한 결과를 비교합니다 |
| **관계 후보 지도** | 같은 문장에 함께 나온 인물·기관을 연결해 보여줍니다 |

모든 점수와 분류는 연구자가 검토해야 하는 **후보**입니다. 판단 근거를 화면에 함께 보여줍니다.

## 사용 방법

### 1. 검색하기 — 통합 검색

1. **연구 대상**에 인물·사건·제도 이름을 넣고 **대상 적용**(또는 Enter)을 누릅니다. 알려진 별칭이 검색어 칸에 채워집니다.
2. **검색어와 별칭** 칸에서 검색어를 고치거나 더합니다. 한 줄에 하나씩 적습니다.
3. **검색 방식**을 고릅니다.

| 검색 방식 | 하는 일 |
|---|---|
| 빠른 검색 (기본) | 목록·서지·요약만 모읍니다. 최대 20번 요청하는 빠른 예비 검색 |
| 목록만 | 요청 횟수 제한 없이 목록만 모읍니다 |
| 우선 본문 30건 | 저장된 목록에서 60점 이상 문헌의 본문을 점수순으로 최대 30건 받습니다 |
| 전체 수집 | 모든 후보의 본문을 받습니다. 오래 걸립니다 |
| 본문 이어받기 | 아직 받지 않은 본문을 이어서 받습니다 |

4. **통합 검색 시작**을 누릅니다. 진행 상황은 아래 상태 표시줄과 **진행 기록** 화면에 나옵니다.
5. 멈추려면 **중단 후 저장**을 누릅니다. 지금까지 받은 내용은 저장되고, 같은 폴더로 다시 실행하면 이어집니다.

추천 순서: **빠른 검색**으로 후보 목록을 먼저 모은 다음, 결과 창에서 필요한 문헌만 골라 본문을 받습니다.

### 2. 검색할 사이트 고르기 — 자료원 연결

| 사이트 | 앱에서 받는 내용 |
|---|---|
| 한국사데이터베이스 · 조선왕조실록 · 승정원일기 | 검색 목록과 **본문** |
| 한국학자료통합플랫폼 · 한국고전종합DB · 디지털장서각 · 우리역사넷 | 검색 첫 화면의 **제목·서지·요약** |
| 규장각 원문검색서비스 · 대한민국 신문아카이브 · 국가기록포털 | 자동 수집 안 함. **공식 검색 ↗ / 사이트 열기 ↗**로 브라우저에서 엽니다(검색어는 클립보드에 복사) |

체크한 사이트만 통합 검색에 씁니다. 서지·요약만 오는 자료의 원문은 결과 창의 **공식 원문 ↗**으로 확인합니다.

### 3. 모은 문헌 읽기 — 문헌 결과 창

**문헌 결과 보기**(또는 **내 문헌 → 문헌·분석 열기**)로 엽니다. 왼쪽은 목록, 오른쪽은 본문입니다.

- **거르기**: 찾기 칸(제목·본문 검색), 자료원, 관점(정치사·사회사·제도사), 연대, 점수(60점·80점 이상).
- **정렬**: 학습 추천순 / 규칙 점수순 / 판정 필요순.
- **선택 문헌 본문 받기**: 목록에서 고른 문헌(여러 개 가능)의 본문만 받습니다. 끝나면 창이 자동으로 새로고침됩니다.
- **원문 주소 복사**, **공식 원문 ↗**: 공식 사이트의 원문 주소를 복사하거나 엽니다.
- 오른쪽 본문 위에 점수·관점·연대·상태와 **점수 근거**(어떤 이름이 제목·요약에 나왔는지)가 표시됩니다.

![문헌 결과 창](docs/screenshots/results.png)

### 4. 관련 문헌을 위로 — 판정 학습

1. 정렬을 **판정 필요순**으로 바꿉니다. 판단이 가장 애매한 문헌부터 나옵니다.
2. 문헌을 읽고 키보드 **1**(관련 있음) 또는 **0**(관련 없음)을 누릅니다. 오른쪽 위 버튼을 눌러도 됩니다. 판정하면 다음 문헌으로 넘어갑니다. 잘못 눌렀으면 **Delete**.
3. 관련·무관을 각각 3건 이상 판정하면 **추천**(0~100) 열이 생기고, **학습 추천순**으로 정렬할 수 있습니다. 판정할수록 정확해집니다.
4. **추천 성능** 버튼: 내 판정을 기준으로 규칙 점수와 학습 추천 중 어느 쪽이 더 잘 맞히는지 보여줍니다.

문헌마다 **추천 근거**(무엇 때문에 추천이 올라가고 내려갔는지)가 본문 위에 표시됩니다.

![판정 학습](docs/screenshots/after-judge.png)

### 5. 주제·자료 유형 주석 달기

결과 창 오른쪽 **주석 줄**에서 합니다.

1. 맨 앞 선택칸에서 과제를 고릅니다: **주제** / **자료 유형** / 직접 만든 과제.
2. 맞는 라벨을 체크하면 바로 저장됩니다. 괄호 안은 규칙이나 모델의 제안입니다.
   - **제안대로**: 제안을 그대로 주석으로 저장
   - **해당 없음**: 어느 라벨도 아님
   - **지우기**: 주석 삭제
3. 주석한 문헌은 목록의 관점 열에 ✎ 표시가 붙습니다.

### 6. 텍스트 분석

결과 창의 **텍스트 분석** 버튼으로 엽니다. **비슷한 문헌** 버튼은 지금 고른 문헌과 비슷한 문헌을 바로 찾아 줍니다.

| 탭 | 사용법 |
|---|---|
| **유사 검색** | 낱말이나 원문 구절(예: `淑嬪崔氏 追崇`, `육상궁 제향`)을 넣고 **유사도 검색**. 겹치는 핵심어가 함께 나옵니다. 두 번 클릭하면 결과 창에서 그 문헌이 열립니다 |
| **어휘 관계** | 낱말을 넣으면 쓰임이 비슷한 말과 자주 함께 나온 말이 나옵니다. **시대**를 바꿔 세기별로 비교합니다 |
| **문맥 용례** | 낱말을 넣고 **용례 묶기**. 그 낱말이 나온 문장들이 쓰임새별로 묶여 나옵니다(예: 같은 호칭이 다른 인물을 가리키는 경우 확인) |
| **주제 분류** | 주제 주석을 몇십 건 단 뒤 **학습 · 전체 분류**. 모델이 새로 찾은 주제는 결과 창 관점 열에 `+` 로 표시됩니다. **예측 결과 CSV로 저장** 가능. 새 주제도 추가할 수 있습니다 |
| **여러 작업 동시 학습** | 여러 과제에 주석을 단 뒤 **비교 실행**. 과제를 따로 학습할 때와 함께 학습할 때의 정확도를 비교하고, 함께 학습이 오히려 나쁜 과제는 ⚠ 로 표시합니다. **새 과제**에 이름과 라벨(쉼표로)을 적어 과제를 만듭니다 |
| **시대·출처 적응** | 도메인(시대 또는 자료집)과 과제를 고르고 **측정 · 적응 비교**. 다른 시대·자료집 자료로 학습한 모델이 얼마나 떨어지는지와, 보정 방법(재가중·GRL)의 결과를 보여줍니다 |

| | |
|---|---|
| ![유사 검색](docs/screenshots/lab-search.png) | ![주제 분류](docs/screenshots/lab-topics.png) |

정확도 비교 숫자는 주석이 많을수록 믿을 만합니다. 주제·도메인마다 10건 이상을 권합니다.
시대에 따른 용어·문체 차이 자체를 연구하는 경우에는 시대·출처 적응 결과를 분류에 쓰지 마세요.

### 7. 기존 결과 다시 열기 — 내 문헌

**내 문헌 → 기존 결과 폴더 선택 → 문헌·분석 열기**. `collection.sqlite3` 또는 `documents.jsonl`이 있는 폴더를 고르면 다시 수집하지 않고 읽습니다. 이전 버전에서 모은 결과도 열립니다.

## 저장되는 파일

결과 폴더(기본: exe 옆 `수집결과`)에 저장되며, CSV는 엑셀로 열립니다.

| 파일 | 내용 |
|---|---|
| `collection.sqlite3`, `documents.jsonl`, `documents.csv` | 모은 문헌 |
| `report.json`, `run.log` | 실행 요약과 기록 |
| `judgments.csv` | 관련/무관 판정 (대상 인물별, 판정 시각 포함) |
| `topic_labels.csv` | 주제·자료 유형·직접 만든 과제 주석 |
| `topic_predictions.csv` | 주제 분류 결과와 라벨별 확률 |

## 단축키

| 키 | 동작 |
|---|---|
| Alt + ← | 메인 창: 이전 화면으로 |
| Esc | 결과 창·분석 창 닫기 (결과 창 찾기 칸에서는 검색어 지우기) |
| 1 / 0 / Delete | 결과 목록에서 관련 / 무관 / 판정 지우기 |
| Enter | 연구 대상 칸: 대상 적용 · 분석 창 입력칸: 실행 |

## 알아둘 점

- 점수·분류·관계는 규칙과 학습으로 만든 **검토용 후보**입니다. 낮은 점수의 문헌도 관련 자료일 수 있습니다.
- 빠른 검색은 일부 결과만 가져옵니다. 사이트의 전체 검색 건수와 실제로 가져온 건수는 보고서에 따로 기록됩니다.
- 서지·요약만 오는 4곳은 전체 본문·이미지를 받지 않습니다.
- 사이트마다 이용·인용 조건을 따라 주세요.
