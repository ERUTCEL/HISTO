# HISTRO

## 실행

`HISTRO.exe`를 더블클릭합니다. Python 설치가 필요 없는 Windows 64비트 실행파일입니다. 기존 결과를 쓰려면 **내 문헌 → 기존 결과 폴더 선택 → 문헌·분석 열기**를 누릅니다. 기존 DB를 다시 수집할 필요가 없습니다.

## 새 화면

- **통합 검색**: 연구 대상, 별칭, 검색 방식, 저장 위치와 현재 보관 문헌 수를 보여줍니다.
- **자료원 연결**: 10개 사이트 카드에서 통합 검색에 사용할 곳을 선택하고 공식 검색 화면을 열 수 있습니다.
- **내 문헌**: 현재 결과 폴더와 최근 기록을 확인하고 내부 문헌·분석 창을 엽니다.
- **진행 기록**: 자료원별 응답과 오류, 저장 상태를 확인합니다.


## 사이트별 연결 범위

| 사이트 | 앱에 합쳐지는 내용 | 공식 사이트 연결 |
|---|---|---|
| 한국사데이터베이스 | 지원하는 자료집의 검색 목록·본문 | 검색어 전달 |
| 조선왕조실록 | 국역·원문 검색 목록과 본문 | 검색어 전달 |
| 승정원일기 | 검색 목록과 본문 | 검색어 전달 |
| 한국학자료통합플랫폼 | 공개 검색 첫 화면의 서지·요약 | 검색어 전달 |
| 한국고전종합DB | 공개 검색 첫 화면의 기사 서지·요약 | 검색어 전달 |
| 디지털장서각 | 공개 검색 첫 화면의 서지·요약 | 검색어 전달 |
| 우리역사넷 | 공개 검색 첫 화면의 제목·요약 | 검색어 전달 |
| 규장각 원문검색서비스 | 앱으로 자동 수집하지 않음 | 홈페이지 열기 + 검색어 복사 |
| 대한민국 신문아카이브 | 앱으로 자동 수집하지 않음 | 검색어를 전달하여 공식 검색 열기 |
| 국가기록포털 | 앱으로 자동 수집하지 않음 | 홈페이지 열기 + 검색어 복사 |

자료원 카드에 **목록·본문 통합 / 서지·요약 통합 / 공식 사이트 연결**을 표시하여 범위를 구분합니다. 추가 4곳의 자동 통합은 전체 본문이나 이미지 다운로드가 아닙니다. 원문은 결과 창의 **공식 원문 ↗**에서 확인합니다.

규장각은 테스트 환경의 직접 HTTP 연결이 끊겼고, 국가기록포털과 신문아카이브는 일반 HTML 응답만으로 검색 목록을 신뢰성 있게 읽을 수 없었습니다. 이 세 곳은 미검증 수집기를 붙이지 않고 공식 사이트 연결로 제공했습니다. 외부 사이트 버튼을 누를 때만 브라우저를 엽니다. 로컬 결과 보기는 계속 앱 안에서 동작합니다.

## 빠른 검색과 분석

기본으로 7개 통합 자료원을 선택합니다. 빠른 검색은 **최대 20회 새 HTTP 요청**과 기존 핵심 자료의 첫 페이지로 범위를 제한합니다. 새로 추가한 4곳은 검색 첫 화면의 미리보기를 수집합니다. 전수 수집 결과가 아니며 전체 모드에서도 이 4곳은 현재 첫 화면 미리보기만 제공합니다.

빠른 모드는 연결 5초·읽기 12초의 요청 타임아웃과 1회 시도를 사용합니다. 요청 간격은 2초입니다. 캐시 재사용은 새 요청에 포함하지 않습니다. 오류나 접근 제한이 생긴 추가 자료원은 실패 내역을 남기고 다른 사이트 검색을 계속합니다. 접근 제한이 난 자료원에는 이번 실행에서 추가 요청을 보내지 않습니다.

관련성 점수, 정치사·경제사·사회사·문화·예술사·사상사·생활·미시사 복수 분류, 기록 연대 필터와 근거가 있는 공동 등장 지도를 재사용합니다. 모두 규칙 기반의 검토 후보입니다. 서지·요약 자료는 **서지·요약** 상태로 표시하고 본문 미수집/수집 실패와 구분합니다. 제목·요약을 전체 본문처럼 표시하지 않습니다.

동일 장서각 ID 또는 알려진 원문 기사 ID를 여러 자료원에서 찾으면 병합하고 발견한 자료원 ID를 보존합니다. 전체 사이트의 모든 판본·번역·표기 변형을 자동으로 동일시하지는 않습니다.

## 검증

2026-10-23, 빈 결과 폴더에서 기본 두 검색어와 통합 자료원 7곳으로 실제 테스트했습니다.

- HTTP 요청 20회, 검색 작업 경과 46.24초 + 최종 내보내기 약 0.4초.
- 후보 235건: 서지·요약 90건, 본문 미수집 핵심 기사 145건.
- 추가 4개 자료원에서 각각 실제 결과를 읽었으며, 기록된 검색 실패는 0건.
- 요청 한도로 종료한 부분 검색입니다. 사이트의 검색 총 건수와 실제 가져온 미리보기 건수는 보고서에 따로 기록됩니다.
- 30개 단위 테스트 통과. Windows EXE를 Python 경로 없는 별도 폴더에서 두 번 실행해 4개 화면, 10개 자료원/7개 통합 선택, 내부 결과 표시, 관계 지도, 캐시 수집과 이어받기를 확인했습니다.

사이트 속도와 응답 내용에 따라 시간이 달라집니다. 위 시간은 기존 프로그램과 동일한 결과량에 대한 비교 측정이 아닙니다.

## 소스 실행 예

```powershell
python collector.py --quick --sources history,sillok,sjw,kdp,itkc,jsg,ourhistory
python collector.py --quick --sources kdp,jsg --term "숙빈 최씨"
python collector.py --download-only --min-score 60 --max-documents 30
```

자동 자료원의 새 연결은 `source_connectors.py`, 화면 스타일은 `ui_theme.py`, 브라우저 연결은 `browser_links.py`에 있습니다. 로그인·API 키 없이 공개 검색을 사용합니다. 사이트별 이용·인용 조건은 그대로 적용됩니다.
