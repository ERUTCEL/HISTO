HISTRO — Windows 64비트

1. HISTRO.exe를 더블클릭합니다. Python 설치는 필요 없습니다.
2. 통합 검색 화면에서 연구 대상·검색어와 검색 방식(버튼)을 고르고 통합 검색 시작을 누릅니다.
3. 자료원 연결(또는 "자료원 7곳 선택됨 · 변경")에서 통합 검색할 사이트를 선택할 수 있습니다.
4. 문헌 결과 보기에서 점수·자료원·역사 관점으로 필터링합니다.

기존 결과: 내 문헌 → 기존 결과 폴더 선택 → 문헌·분석 열기.
collection.sqlite3 또는 documents.jsonl이 있는 폴더를 선택하세요. 재수집할 필요가 없습니다.

10곳 연결: 한국사DB·실록·승정원일기의 목록·본문, 추가 4곳의 서지·요약을 앱에 합칩니다.
규장각·신문아카이브·국가기록포털은 공식 사이트로 연결합니다.
빠른 검색은 최대 20회 새 요청과 미리보기로 제한된 부분 검색입니다.
서지·요약 자료의 원문은 공식 원문 버튼에서 확인합니다.

결과는 기본적으로 EXE 옆 수집결과 폴더에 저장됩니다.
중단은 중단 후 저장, 이어받기는 같은 결과 폴더로 다시 실행합니다.
점수·분류·관계는 연구자가 검토해야 하는 규칙 기반 후보입니다.
자세한 내용은 상세사용법.md를 참고하세요.

- Pretendard 글꼴 내장, 고해상도(125%·150%) 화면에서 선명하게 표시
- 검색 방식 버튼, 수집 중에만 나타나는 진행 막대, 결과 창 좌우 배치
- 뒤로가기: 메인 창 제목 옆 "← 이전 화면" 버튼 또는 Alt+←, 결과 창·관계 지도는 "← 연구실로/결과로" 버튼 또는 Esc
- 판정 학습: 결과 창에서 문헌을 고르고 1(관련) / 0(무관) / Delete(지우기). 관련·무관 각 3건 이상이면 '추천' 순서로 정렬됩니다.
  정렬 '판정 필요순'은 헷갈리는 문헌부터 보여줍니다. '추천 성능' 버튼으로 규칙 점수와 비교할 수 있습니다.
  판정은 결과 폴더의 judgments.csv에 남습니다.
- 텍스트 분석(결과 창 버튼): 비슷한 문헌 찾기, 함께 쓰인 말(시대별), 쓰임새 보기,
  자동 분류. 주제 표시는 결과 창 오른쪽 표시 줄에서 체크합니다.
- 여러 분류 함께 학습: 결과 창 표시 줄에서 분류(주제/자료 유형/직접 만든 분류)를 바꿔 표시 → 텍스트 분석 '여러 분류 함께 학습' 탭에서 비교하기.
  함께 배우면 나빠지는 분류는 ⚠로 표시됩니다.
- 시대·자료집 차이 점검: 같은 이름의 탭에서 시대 또는 자료집을 고르고 점검하기. 정확도가 떨어질 때만 보완 결과를 참고하세요.
- 즐겨찾기: 결과 창에서 F(문헌 통째) 또는 본문 일부를 끌어 선택하고 Ctrl+S. 왼쪽 메뉴 '즐겨찾기'에서 분류를 만들고 옮깁니다.
  분류마다 exe 옆 '내 즐겨찾기' 폴더에 .md(메모장으로 열림) 파일이 생깁니다.
- 검색어 표시: 결과 창 본문에서 검색어가 나온 자리가 굵게·노란 바탕으로 표시됩니다. '검색어가 나온 문헌만'으로 관련 없는 결과를 숨길 수 있습니다.
- 검색 범위: '목록만'·'전체 수집'은 사이트별로 볼 쪽 수를 고릅니다(기본 3쪽). '↺ 검색 초기화'로 검색 조건을 처음 상태로 되돌립니다.
- 검색마다 따로 저장: 검색어가 바뀌거나 초기화한 뒤 검색하면 결과가 '수집결과' 안의 새 폴더(대상 이름 + 날짜 시각)에 저장되어 이전 결과와 섞이지 않습니다. 같은 검색어로 다시 검색하면 그 폴더에 이어서 저장합니다. 이전 결과는 결과 창의 '다른 결과 폴더'로 엽니다.
- 본문 펼치기: 본문을 아직 받지 않은 문헌은 결과 창 오른쪽에 검색 화면의 짧은 글만 보입니다. '▼ 본문 펼치기'(또는 Enter)를 누르면 그 문헌의 본문 전체를 원문 사이트에서 받아 그 자리에 펼칩니다. 검색 조건은 바뀌지 않습니다.
- 읽기 좋은 본문: 본문은 문단별로 나뉘어 보입니다. 원문(한문)과 주석(낱말 풀이)은 아래에 접혀 있고 '▸ ... (펼치기)'를 누르면 펼쳐집니다. 본문 속 [註 001]을 누르면 해당 풀이로 갑니다.
